2. 题目、规则、答案和统计的 ID 关联
- surveys._id 是问卷标识；questions.surveyId 和 responses.surveyId 引用它。questions 是独立集合，题目按同一问卷内的 order 排列，(surveyId, order) 有唯一索引。依据：[schema.py](C:/Users/24222/Desktop/数据库/survey-system/backend/app/db/schema.py)、[questions.py 路由](C:/Users/24222/Desktop/数据库/survey-system/backend/app/routers/questions.py)。
- 题目以 questions._id 标识。每道选择题的选项另有字符串 id；同题已有选项在编辑时可保留 ID。规则保存在来源题目的 jumpRules 中，含自身 id、priority、目标 targetQuestionId，选择题条件用 optionIds 引用该题选项。目标须是同一问卷中顺序更靠后的题目。依据：[questions.py 路由](C:/Users/24222/Desktop/数据库/survey-system/backend/app/routers/questions.py)、[jumps.py](C:/Users/24222/Desktop/数据库/survey-system/backend/app/services/jumps.py)、[schema.py](C:/Users/24222/Desktop/数据库/survey-system/backend/app/db/schema.py)。
- 提交请求逐项携带 questionId 和值：单选值是选项 ID，多选值是选项 ID 数组，文本和数字存其值。服务端从首题按优先级规则重算路径；持久化的 answers 只包含实际回答，visitedQuestionIds 则包含所有到达的题目，包括选答留空题。依据：[api.md](C:/Users/24222/Desktop/数据库/survey-system/docs/api.md)、[responses.py 服务](C:/Users/24222/Desktop/数据库/survey-system/backend/app/services/responses.py)、[responses.py 路由](C:/Users/24222/Desktop/数据库/survey-system/backend/app/routers/responses.py)。
- 统计按 surveyId 读取答卷，以 visitedQuestionIds 计算到达数、以 answers[].questionId 计算回答数；选择题再用答案中的选项 ID 对照题目选项计数。文本、数字原始内容来自答卷，数字平均值基于有效数字答案实时计算；没有单独的统计汇总集合。依据：[statistics.py 服务](C:/Users/24222/Desktop/数据库/survey-system/backend/app/services/statistics.py)、[design.md](C:/Users/24222/Desktop/数据库/survey-system/docs/design.md)。

旧数据的关键解释关系是：现有 surveyId 归属、题目 _id 与选项 id 引用、规则目标与条件引用，以及答卷的 answers 和 visitedQuestionIds。已发布问卷的题目及规则当前禁止修改；否则历史答案可能无法按原题和原选项解释。匿名答卷仍存 respondentId 以约束重复填写，但统计展示隐藏身份。禁止重复填写时，responses 的部分唯一索引约束同一问卷、同一填写者。依据：[大作业一：需求变更.docx](C:/Users/24222/Desktop/数据库/大作业一：需求变更.docx)、[questions.py 路由](C:/Users/24222/Desktop/数据库/survey-system/backend/app/routers/questions.py)、[responses.py 路由](C:/Users/24222/Desktop/数据库/survey-system/backend/app/routers/responses.py)、[statistics.py 服务](C:/Users/24222/Desktop/数据库/survey-system/backend/app/services/statistics.py)、[schema.py](C:/Users/24222/Desktop/数据库/survey-system/backend/app/db/schema.py)。
